\# CodeAlpha Web Scraping Project



\## Project Overview

This project collects book information from the public practice website Books to Scrape using Python.



\## Objective

To extract book titles, prices, and availability from webpage HTML and store the results in a CSV dataset.



\## Technologies Used

\- Python 3.11

\- Requests

\- BeautifulSoup

\- Pandas



\## Features

\- Downloads webpage content

\- Parses HTML elements

\- Extracts book titles, prices, and availability

\- Saves the collected data to `books\_data.csv`



\## How to Run

1\. Install the required libraries:

&#x20;  `py -m pip install requests beautifulsoup4 pandas`

2\. Run the scraper:

&#x20;  `py scraper.py`



\## Output

The program generates `books\_data.csv` containing the scraped book information.

https://books.toscrape.com/
